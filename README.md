# Homebrew tap

Homebrew casks for apps by [Aleksei Popov](https://devopscode.pro).

## Macaffeine

A tiny, native macOS menu bar app that keeps your Mac awake while you're away — [macaffeine.app](https://macaffeine.app).

```sh
brew install --cask devopscodepro/tap/macaffeine
```

This also puts the `macaffeine` command line tool on your `PATH`.

Update with `brew upgrade --cask macaffeine`, remove with `brew uninstall --cask macaffeine` (add `--zap` to delete its settings too).
